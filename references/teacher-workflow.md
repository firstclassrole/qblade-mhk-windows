# 从教学教程提炼的原生工作流

来源为 `EG-3100 - Week 3 - QBlade`，34页课堂课件。以下为原创归纳及页码索引，不附课件原文或截图。课堂示例说明怎样使用软件，不替代项目输入、性能证据或制造验收。

## 操作顺序与每步检查

| 步骤 | 教程位置 | 做什么与检查什么 |
|---|---|---|
| 翼型 | 11–13页 | 生成四位数NACA、导入Selig坐标、插值翼型；检查轮廓、弦长归一化与厚度。 |
| 有限迎角 polar | 15–17页 | 按实际Re求升阻力，必要时建立多Re批次。检查每条实际保存的角度，不仅看扫描输入框。 |
| 360°外推 | 19–21页 | 比较Viterna、Montgomerie的连接；后者需要调整连接区。检查有限角度数据是否被正确保留。 |
| 叶片站位 | 23–24页 | 设置Pos/Chord/Twist/Foil/Polar。站位是一处截面，不是一片叶片；Root Coordinates改变显示基准。 |
| 原生Optimize | 25页 | 指定TSR与优化站位，生成候选弦长/扭角；非捕能连接段按实际结构排除。 |
| 尺寸与水槽 | 26页 | 检查完整转子直径、水深和净空；厚根至薄尖是示例布置，不是强制型号。 |
| BEM与敏感性 | 28–29页 | 设置流体物性、叶素数及TSR扫掠。通过细化比较结果是否稳定。 |
| VAWT | 31–33页 | Height、Radius、TOffset与HAWT径向叶片定义不同。不能照搬HAWT的弦长/扭角优化。 |

第9页展示主链：**翼型 → 极曲线 → 360° → 叶片 → BEMT**。本skill在关键输入和结果之间增加可追溯核查；这些核查是实践总结，不冒称老师逐字规定的评分标准。

## 不要机械照抄示例

- 练习出现圆形及NACA4408、4412、4416、4420，不代表设计只能用这四个翼型；也不代表圆形连接段可用XFOIL按普通翼型分析。
- 第25页示例的TSR4.5、站位2–10、Opt Lift/Drag偏移+2°、Betz弦长，都需要按自己的几何与工况重新决定。只有确实存在非捕能第一站，才有排除它的理由。
- 教程Auto Spacing会复制第一站属性。新增站位后逐行检查翼型和polar，避免所有截面意外使用同一组合。
- 第26页的叶片跨度与轮毂半径必须一起换算转子直径。名义直径刚好小于水深，不等于留足自由液面、底部、支承和变形净空。
- 第28–29页示例polars的Re约一百万，不能代表厘米级叶片的低Re。截图里黏度的数量级也需独立核对水温及单位，不能当水的默认值。
- 第32页对VAWT优化的说明不能当成HAWT捕能优化的等价功能。

## 从课堂流程走向可复查设计

先明确原型、流向和尺寸，再准备正确截面的数据。基准、扭角对照与弦长对照分别命名；按实际按钮执行Optimize并记录前后表。完成仿真后检查局部流动和数值敏感性，而不只截图峰值Cp。

如果用户要求阶段验收，选型、流体分析、制造细化各自给出结果与待补证据，在约定节点提示用户；不自动把“模型外形通过”解释为“仿真与制造均通过”。

官方可交叉核对：[翼型分析](https://docs.qblade.org/src/user/airfoil/airfoil.html)、[叶片定义](https://docs.qblade.org/src/user/blade/blade.html)、[BEM](https://docs.qblade.org/src/user/bem/bem.html)。不同版本菜单与求解器可有差异，使用前核对当前界面。
