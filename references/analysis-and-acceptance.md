# 水动力分析与结果验收

## 选对模块与工况

HAWT径向叶片使用BEM；升力型VAWT使用DMS/AC。官方将稳态工具定位为初步性能分析，不是完整自由液面CFD。Rotor、Characteristic、Turbine子模块的自变量和输出不同，先核对当前模块再解释数据。

官方Rotor BEM/DMS文档描述以无量纲参数计算；本机特定HAWT archive又观察到已保存的有量纲数组。这种差异必须以实际版本、原生输出、单位和归一化核对，不能凭二进制里的浮点数猜载荷。不能据此声称所有模块都提供同样的有量纲列。

水流工况需要水的ρ和运动黏度ν。旧界面即使保留Air/Wind字样，也不能继续用空气物性。记录物性来源或水温假设；完整MHK设置还有浮力、附加质量等问题，但不把这些自动宣称为简单稳态BEM已经包含的物理。

每个案例记录：叶片与polar身份、U、ρ、ν、pitch、TSR/RPM范围、步长、叶素数、迭代上限、epsilon、松弛与修正选项。命名区分流速、几何和设置。显示0.0000不证明epsilon为零。

## 先核查代数，再核查数值和物理

定义`ω=2πn/60`、`λ=ωR/U`；n为rpm、R为叶尖半径。检查：

- `Cp≈λCq`，`P≈ωQ`（此处Q为转矩）。
- 有合格有量纲量时，用非零且数值条件良好的行反算`A=P/(0.5ρU³Cp)`、`A=T/(0.5ρU²Ct)`，并核对转矩对应面积。
- 用`R≈λU/ω`核对半径，检查整片/单片、全转子、单位和符号。

曾核对的一组HAWT数据按完整圆盘`πR²`归一化，而叶片界面显示环形面积。这是提醒逐例反算，不是所有QBlade模块的通则。

恒等式通过只说明变量自洽。还要检查局部AoA与Re是否落在受支持的polar范围、诱导因子及高推力分支是否适用、峰值是否由缺点/端点形成、求解是否收敛。局部诱导异常或高TSR负功率尾部不直接当结构设计极限。

选定候选正功率区域后，适当细化叶素、TSR步长和求解设置，比较Cp、转矩与局部分布。阈值按任务精度和数据误差决定，不虚构统一“通过”百分比。两个流速使用同一固定polar时系数接近，不证明Re影响已经处理。

VAWT还应核查方位角、上下游通过、瞬时及平均转矩、动态失速和支撑影响；正平均稳态转矩不能证明静止起动。

## 怎样解释负功率或负效率

保持原始符号。按能量提取为正的约定，P<0意味着该指定工况下外界要向转子输入轴功。可能是过高转速、不合适的pitch/旋向、曲线输入、符号约定或模型超适用范围，需要诊断；不能取绝对值变成发电。

`Pshaft/Pkin<0`是有符号提取系数的负值，不是“损失超过100%”的普通发电效率。先说明分子分母和控制体。小水流有能量不等于任意叶形、任意强制转速都能取出正功率。

结论分别写：输入是否可用、数值是否稳定、方法是否适用、实际功率属于估算还是仿真、能否支撑当前验收。正轴功与发电机带载输出分开。

## 可选只读QPR提取器

优先原生导出。只有确认**HAWT Rotor BEM、archive310043、已核实十数组结构**时，才用：

```bash
python scripts/extract_qpr_bem.py working.qpr --module hawt-rotor-bem --object-name EXACT_CASE --rho 1000 --rotor-radius 0.09 --hub-radius 0.018 --blade-count 3 --locate-only
```

上述密度与尺寸仅展示参数格式。真实值须来自工程。检查唯一候选后，去掉`--locate-only`并指定独立`--out-dir`和`--prefix`。输出为保存数组与审计，不是重新仿真。

它检查版本头、精确对象名、数组长度和物理恒等式；不支持DMS/AC/VAWT、不实现完整QPR序列化，也不证明输入正确或收敛。字段` saved_blade_bending_unverified_Nm `含义仍未核实，不得重命名为轴弯矩或叶根弯矩。布局、面积或恒等式不匹配时停止该路线，改用原生导出或调查版本。
